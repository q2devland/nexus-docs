Configuration reference

Everything a deployment configures is an environment variable of Nexus’s container, read once, as Nexus starts: changing one is restarting Nexus with it. None is kept in the database, and none is shown anywhere, in Settings or the API. The rest, from the data model to the Project’s name and branding, admins set in Nexus itself.

A value Nexus can’t use stops it from starting, with an error that names the variable and says what it takes, such as NEXUS_JWT_SECRET is required, at least 32 characters long. A variable that’s set but empty is as good as unset.

Some take values of a kind:

  • A duration is a whole number and a unit, without a space: s, m, h or d, such as 90s, 15m, 12h or 30d. The Read model’s take ms, s or m, such as 500ms.
  • A size is a number of bytes, or of KB, MB or GB of 1024, such as 500KB, 50MB or 2GB.
  • A list is its items between commas, such as https://www.reelhouse.example,https://app.reelhouse.example.

The Docker image sets four of them itself, which the Default column says: NEXUS_PORT, NEXUS_WEB_ROOT, NEXUS_DOCS_ROOT and NEXUS_STORAGE_PATH.

The server

Section titled “The server”
Variable Default What
NEXUS_DATABASE_URL Required. The PostgreSQL database, as postgres://user:password@host:5432/database, with the password’s special characters percent-encoded. See Database.
NEXUS_PORT 3000 The port Nexus listens on, for the web app, the API and the documentation alike.
NEXUS_WEB_ROOT /app/web in the image; unset, none. The folder of the compiled web app, which Nexus serves beside the API. Unset, it serves only the API, under /api.
NEXUS_DOCS_ROOT /app/docs in the image; unset, none. The folder of this documentation, as the image builds it for its version, which Nexus serves under /docs to anyone, signed in or not. Unset, there is no /docs, and the web app’s link to the documentation opens the latest, on q2devland.github.io/nexus-docs.
NEXUS_PUBLIC_URL Each request’s own. Where people reach Nexus, such as https://cms.reelhouse.example: the address Identity providers send them back to, and Invitations link to. Unset, it’s the address each request came to, as a proxy on a private network forwards it; set it when the proxy that ends TLS is anywhere else.

Secrets and sessions

Section titled “Secrets and sessions”
Variable Default What
NEXUS_JWT_SECRET Required. Signs the access tokens Nexus gives the web app, at least 32 characters, its own for each Project. Changing it signs no one out: the web app asks its session for new tokens, and only a sign-in under way starts again.
NEXUS_ENCRYPTION_KEY NEXUS_JWT_SECRET Encrypts the secrets Nexus keeps and reads back, such as Webhooks’ signing secrets and secret headers, at least 32 characters. Changing it loses them, until admins give them again; set it apart from NEXUS_JWT_SECRET to change that one freely.
NEXUS_ACCESS_TOKEN_LIFETIME 15m A duration: how long an access token of the web app works. Its session gives it a new one before then.
NEXUS_REFRESH_TOKEN_LIFETIME 30d A duration: how long a session lasts once someone signs in, before they sign in again.

Sign-in

Section titled “Sign-in”
Variable Default What
NEXUS_BOOTSTRAP_ADMIN_EMAIL None. Who becomes the first User, with the Admin role, as Nexus starts on an empty Project. Ignored once the Project has Users. See The first admin.
NEXUS_IDENTITY_PROVIDERS None: nobody can sign in. A list of the Identity providers people sign in with, by names of your choosing, in the order the sign-in page offers them. Each is configured by the variables below; one configured but not listed is disabled.
NEXUS_GOOGLE_<NAME>_CLIENT_ID Required for a Google provider. Its OAuth client’s ID, <NAME> being the provider’s name in upper case.
NEXUS_GOOGLE_<NAME>_CLIENT_SECRET Required for a Google provider. Its OAuth client’s secret.
NEXUS_MICROSOFT_<NAME>_CLIENT_ID Required for a Microsoft provider. Its app registration’s application (client) ID.
NEXUS_MICROSOFT_<NAME>_CLIENT_SECRET Required for a Microsoft provider. Its client secret’s value.
NEXUS_MICROSOFT_<NAME>_TENANT common Whose accounts sign in: a tenant’s ID or domain, organizations, consumers or common.
NEXUS_GOOGLE_<NAME>_ISSUER, NEXUS_MICROSOFT_<NAME>_ISSUER Google’s, or the tenant’s at Microsoft. Another issuer for the provider, replacing its own: only for testing, with a fake identity issuer such as the Reelhouse demo’s.

NEXUS_GOOGLE_CLIENT_ID, NEXUS_GOOGLE_CLIENT_SECRET and NEXUS_GOOGLE_ISSUER, without a provider’s name, as Nexus once read them, stop it from starting: name the provider in NEXUS_IDENTITY_PROVIDERS and move them under that name. See Identity providers.

Email

Section titled “Email”
Variable Default What
NEXUS_SMTP_URL None: no Invitation can be sent. The SMTP server Invitations are sent through, as smtp://host:587, upgraded to TLS when the server offers it, or smtps://host:465, with the user and password in it if it needs them.
NEXUS_SMTP_FROM Required with NEXUS_SMTP_URL. The address mail comes from, alone or as Name <address>.
NEXUS_INVITATION_LIFETIME 7d A duration: how long an Invitation’s link works.

See Email.

Files

Section titled “Files”
Variable Default What
NEXUS_STORAGE local Where Files are kept: local, s3, azure or gcs.
NEXUS_STORAGE_PATH /data/files in the image; unset, storage in the working directory. local: the folder they’re kept in.
NEXUS_S3_BUCKET Required for s3. The bucket, which must exist.
NEXUS_S3_REGION The AWS SDK’s own, such as AWS_REGION; us-east-1 with NEXUS_S3_ENDPOINT. Its region.
NEXUS_S3_ACCESS_KEY_ID The AWS SDK’s own credentials. An access key, with NEXUS_S3_SECRET_ACCESS_KEY: both or neither.
NEXUS_S3_SECRET_ACCESS_KEY The AWS SDK’s own credentials. Its secret.
NEXUS_S3_ENDPOINT AWS. Another service that speaks S3, such as MinIO or Cloudflare R2, addressed by path.
NEXUS_AZURE_CONNECTION_STRING Required for azure. The Azure Storage account’s connection string.
NEXUS_AZURE_CONTAINER Required for azure. The container, which must exist.
NEXUS_GCS_BUCKET Required for gcs. The bucket, which must exist.
NEXUS_GCS_KEY_FILE Application Default Credentials. The path of a service account’s JSON key.
NEXUS_GCS_ENDPOINT Google’s. Another API that speaks GCS’s, such as an emulator, called without credentials unless a key file is given.
NEXUS_UPLOAD_MAX_SIZE 50MB A size: the largest File anyone may upload. A File or Image Field may take smaller ones only.

See File storage.

Cache

Section titled “Cache”
Variable Default What
NEXUS_REDIS_URL None: the model is read from the database on every request. The Redis the data model is kept in, shared by every instance of the Project, as redis://host:6379 or rediss://host:6380, with the user and password in it if it needs them. A Project running several instances needs it to have a cache.
NEXUS_REDIS_TIMEOUT_MS 50 Milliseconds Redis may take to answer before the database does, from 1.
NEXUS_MODEL_CACHE_TTL_SECONDS 86400 Seconds Redis keeps what it was told of the model, from 1.

See Cache.

Security

Section titled “Security”

Every Project starts with secure defaults; these override them, only when needed.

Variable Default What
NEXUS_CORS_ORIGINS None: only the web app. A list of the origins of other websites whose pages may call the API with an API token, or * for any. Cookies are never sent from them.
NEXUS_PREVIEW_ORIGINS None. A list of the origins the Item view may show previews from, in a frame: the frame-src of the Content-Security-Policy.
NEXUS_IMAGE_ORIGINS None. A list of the origins the app may show Image URLs and their URL previews from, and Video keys’ thumbnails, added to the img-src of the Content-Security-Policy.
NEXUS_VIDEO_ORIGINS None. A list of the origins the app may play Video keys from, in a frame: added to the frame-src of the Content-Security-Policy, with the preview origins.
NEXUS_RATE_LIMIT 3000/1m How many API requests each client address may make in a window, a duration, such as 1000/1m, or off. Each replica counts its own. The address is the one a proxy on a private network forwards, so such a proxy must overwrite X-Forwarded-For. See Errors and limits.
NEXUS_HEADER_<NAME> Nexus’s headers. Sets the response header <NAME>, its underscores read as hyphens, replacing Nexus’s or adding one; off drops it. NEXUS_HEADER_REFERRER_POLICY=strict-origin-when-cross-origin sets Referrer-Policy.

Nexus sends with every response:

Header Value
Content-Security-Policy default-src 'self'; script-src 'self'; style-src 'self' 'unsafe-inline'; img-src 'self' data: blob:; font-src 'self' data:; connect-src 'self'; object-src 'none'; base-uri 'self'; form-action 'self'; frame-src 'none'; frame-ancestors 'none', with frame-src the preview and video origins, if any, and the image origins added to img-src
Strict-Transport-Security max-age=31536000
X-Content-Type-Options nosniff
X-Frame-Options DENY
Referrer-Policy no-referrer
Cross-Origin-Opener-Policy same-origin
Cross-Origin-Resource-Policy same-origin

NEXUS_HEADER_CONTENT_SECURITY_POLICY replaces the whole policy, and can’t be set with NEXUS_PREVIEW_ORIGINS, NEXUS_VIDEO_ORIGINS or NEXUS_IMAGE_ORIGINS: add the origins to its frame-src or img-src instead.

Webhooks

Section titled “Webhooks”
Variable Default What
NEXUS_WEBHOOK_TIMEOUT 10s A duration: how long a call of a Webhook may take before it fails.
NEXUS_WEBHOOK_RETRY_DELAY 30s A duration: how long the first retry of a failed call waits, each next one waiting twice as long.

Read model

Section titled “Read model”
Variable Default What
NEXUS_READ_MODEL_INTERVAL 2s A duration in ms, s or m: how often each replica rebuilds the Items queued. See Rebuilds and the queue.
NEXUS_READ_MODEL_INCLUDE_DEPTH 10 How many levels of related Items a query may include, from 1.
NEXUS_READ_MODEL_TRIES 5 How many times an Item whose rebuild fails is tried before it’s listed as failed, from 1.
NEXUS_READ_MODEL_RETRY_DELAY 10s A duration in ms, s or m: how long the first retry of a failed rebuild waits, each next one waiting twice as long.

Repeaters

Section titled “Repeaters”
Variable Default What
NEXUS_REPEATER_ROWS_MAX 500 The most Rows any Repeater holds, whatever its own maximum, from 1.
NEXUS_REPEATER_FIELDS_MAX 50 The most Repeater fields a Repeater has, from 1.

Lowering either breaks nothing: a Repeater that holds more keeps it, and only grows no more.

Extensions

Section titled “Extensions”
Variable Default What
NEXUS_EXTENSIONS None. A list of the folders of the Extensions to load, relative to the working directory, /app in the image, unless absolute, in the order their Extension hooks run.
NEXUS_EXTENSION_<NAME>_<SETTING> None. An Extension’s own setting, <NAME> its name in upper case with _ for -, which reaches it as config.<SETTING>. See Configuration.
